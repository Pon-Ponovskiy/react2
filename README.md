# Викторина по React

Сайт-викторина с вопросами по React, прогресс-баром и подсчетом результатов.

## Как установить

1. Скачать архив с GitHub и открыть его через любой редактор кода.
2. Открыть терминал/консоль и установить node.js если не установлен:
   
   sudo apt install nodejs

3. Установить зависимости в проекте:
   
   npm install

4. Запустить проект написав в консоль/терминал:
   
   npm start

## Как работает

1. Пользователь видит вопрос и 3 варианта ответа
2. При выборе ответа проверяется его правильность
3. Если ответ верный, счетчик правильных ответов увеличивается
4. Прогресс-бар заполняется в зависимости от количества отвеченных вопросов
5. После всех вопросов показывается результат с количеством правильных ответов

## Компоненты проекта

**App.js** - главный компонент, который хранит массив вопросов и управляет состоянием (текущий шаг и количество правильных ответов)

**Game.jsx** - компонент викторины, который отображает вопросы, варианты ответов и прогресс-бар

**Result.jsx** - компонент результата, который показывает сколько ответов отгадано

## Цель работы

Сайт сделан в обучающихся целях для изучения React, работы с пропсами и хуком useState
